AND101 Project 3 - AnimalApps
Submitted by: Mohammad Fayyaz

Time spent: 4 hours spent in total

Summary
AnimalApps is an android app that recreates the UI from the Klima app, but with a "Koala" theme. The app was built from scratch to practice creating layouts with ConstraintLayout, TextViews, and ImageViews in XML.
